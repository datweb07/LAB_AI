# Hướng dẫn chạy

1. Cài Python 3 nếu máy chưa có, rồi mở PowerShell và chuyển vào thư mục bài 4:

   ```powershell
   Set-Location 'D:\LAB_AI\bai4'
   ```

2. Cài thư viện cần thiết:

   ```powershell
   python -m pip install python-constraint
   ```

3. Chạy lệnh tương ứng với bài muốn xem. Kết quả sẽ hiển thị trong PowerShell.

   ```powershell
   python .\4quanhau.py
   python .\Matmasohoc.py
   python .\Rangbuocsohoc.py
   python .\TomaunuocUc.py
   python .\Vidunho3bien.py
   ```
